REFLECTION

Coding has always been quite intimidating to me, even when I have learned it a little bit before in a previous module which I took. Still, at the start of this module, my knowledge was quite rusty, and I’ve forgotten a lot of the p5js functions that I’ve learned previously, and had to relearn them all over again. This mini project feels like a culmination of everything that I have learned in this module from the beginning of week 1 until now, and I try my best to make sure I apply and demonstrate what I’ve learned in this mini project.


Initially, I wanted to choose Pong instead of the Flappy Bird project. But as I was thinking about the concept and aesthetic, I thought the format of Flappy Bird would suit my concept better, which is that of a Virus and how it has to go through a person’s immune system to “win”. My focus at first was just to make the game functional first, and to make sure I tick all the requirements (collision, game over state, score board). Which was difficult enough, even with the foundation, hints, and notes that were given in the original files.


I wanted to challenge myself by making all the assets inside p5js, instead of importing assets. But once I re-skinned the game to fit my concept, I then had to figure out and re-do the collision again, because instead of just rectangles, my bars have a rounded thing at the tip which was inspired by uvula. So it’s a combination of rectangle and circular collision. I think the lesson here is to layout my plan first, so that I don’t have to make changes again later. If I had decided the shape of my bird and bars from the beginning, I think the process would’ve been less frustrating.
